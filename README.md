# Z.E Family AI Code Security Scanner

A lightweight AI-powered security scanner for Python repositories.

## Features

- Scan public GitHub repositories
- Upload ZIP archives of Python projects
- AI-generated vulnerability reports
- Severity filter
- Scan history
- JSON export
- Clean mobile-friendly UI

## Tech Stack

- Flask
- Requests
- OpenAI API
- HTML/CSS/JavaScript

## Run locally

```bash
pip install -r requirements.txt
export OPENAI_API_KEY=your_key_here
python server.py
